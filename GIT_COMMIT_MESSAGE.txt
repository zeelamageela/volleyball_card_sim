Phase 5: Comprehensive Matching System Implementation

Major update implementing sophisticated card matching mechanics that resolve
~27% of all rallies, creating balanced competitive gameplay at 50-60% win rates.

## Features Added

### Comprehensive Matching System
- Blocker-blocker matches (identical double-block) → Defender wins (14-15% of rallies)
- Single attacker deflections (attacker matches blocker) → Attacker wins (12-13% of rallies)
- Attacker-attacker matches (front+back same value) → Defender wins (<0.5% of rallies)
- Partial lane matching for multi-attacker scenarios
- Multi-lane processing (high-to-low by attack value)
- Context-based winner determination

### New Abilities (Phase 5)
- FORCE_HIGH_BLOCK: Ignore blocks at or below threshold (Titan, Breaker)
- DECK_SWAP_OPPONENT: Replace opponent's highest card on dig success (Thief)
- WILD_BLOCK: Low-value cards can block any lane (Flex, Shield) - defined, not in strategy yet

### New Players
- Flex (MB): wild_block ≤4, block_value_bonus
- Shield (MB): wild_block ≤5, adjacent_block_bonus
- Titan (OPP): force_high_block ≤5, attack_value_bonus
- Breaker (OPP): force_high_block ≤6, over_block_bonus
- Thief (DS): deck_swap_opponent, chase_card_bonus

### Balance Improvements
- Increased attacker capacity (sets 1-7: max 3, sets 8-10: max 4)
- Win rates improved from 85-93% to 50-60% (competitive balance)
- Matching creates ~27% of scoring (significant tactical layer)
